# Development

This repository is both the plugin package and its test harness:

```
src/        plugin sources, entry point src/index.ts
tests/      unit/regression scripts run by node tests/run.js
scripts/    build-time only helper (marks dist/ as CommonJS)
dist/       generated by `npm run compile`; not committed
```

## Why the compile step exists

The package ships TypeScript sources and OpenCode loads `src/index.ts` directly
(`exports["."]`). The test harness is plain CommonJS and loads compiled files
from `dist/`, so `tsconfig.json` emits CommonJS. Because the package root is
ESM (`"type": "module"`), `scripts/mark-dist.cjs` writes
`dist/package.json` with `{"type":"commonjs"}` after each build. `dist/` is
git-ignored and is not part of the published package.

## Commands

```bash
npm install
npm run compile     # tsc -> dist/
npm test            # compile, then run every tests/*.js
npm run test:only   # run the tests against an existing dist/
node dist/cli.js read/write/grep/patch ...   # standalone debugging CLI
```

Tests use the OS temp directory (`tests/helpers/tmp.js`) and never a fixed
developer path. The `shell` tests execute PowerShell commands and are skipped
on non-Windows platforms.

## Adding a test

Drop a `*.js` file in `tests/`. `tests/run.js` executes every top-level script
and treats a non-zero exit code as a failure. Use `tests/helpers/tmp.js` for
scratch paths:

```js
const tmp = require("./helpers/tmp");
const dir = tmp("my-case");
```
